# Installation Guide

## Requirements

- Node.js `^20.19.0 || >=22.12.0` (Node 21 is not supported)
- npm 10+

## Install dependencies

```bash
npm install
```

## Run in development mode

```bash
npm run dev
```

The app is served by Vite (default: `http://localhost:5173`).

## Build for production

```bash
npm run build
```

## Preview production bundle

```bash
npm run preview
```
